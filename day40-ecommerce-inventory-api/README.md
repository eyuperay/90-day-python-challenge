# 🚀 Day 40 - E-Commerce Inventory Management API

## 📌 Proje Hakkında
Bu proje, **FastAPI** kullanılarak geliştirilmiş tam fonksiyonel bir **E-Ticaret Envanter Yönetim API'sidir**.
40. gün eğitim projesi olarak hazırlanmıştır.

## 🛠️ Kullanılan Teknolojiler
- **FastAPI** - Web framework
- **PostgreSQL** - Veritabanı
- **SQLAlchemy** - ORM
- **Redis** - Cache
- **Docker** - Containerization
- **JWT** - Authentication
- **Pytest** - Testing

## 📦 Özellikler
- ✅ Kullanıcı Kaydı ve Giriş (JWT)
- ✅ Ürün Yönetimi (CRUD)
- ✅ Kategori Yönetimi
- ✅ Sipariş Yönetimi
- ✅ Envanter Takibi
- ✅ Redis ile Caching
- ✅ Docker ile Kolay Kurulum
- ✅ Swagger UI Dokümantasyonu
